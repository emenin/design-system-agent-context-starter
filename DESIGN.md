# Design system context

Use the existing design system when creating or changing UI.
The linked sources are the source of truth.

## Sources of truth

- Tokens: [path or URL]
- Components and APIs: [path or URL]
- Patterns: [path or URL]
- Component rules: `components/<name>/rules.md`

## Before building

- Identify only the components, tokens, and patterns the task needs. Don't scan the whole system.
- Read their usage guidance and, if available, their `rules.md`.
- Don't invent components, variants, or rules.
- If guidance is missing or conflicts, flag the unresolved decision rather than guessing.
