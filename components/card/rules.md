## Usage decisions

- Use `Default` for standard layouts,
  especially with multiple Cards.
  Why: it blends into the page background.

- Use `Subtle` when a Card needs additional
  visual separation from its surroundings,
  such as in nested layouts.
  Why: using it repeatedly on the page
  background creates unnecessary visual weight.
